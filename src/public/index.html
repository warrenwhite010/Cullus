Mode Anywhere in your vault
auto asks you first, then writes

Chat transcripts, config.json and tokens stay out of the vault: transcripts are noisy JSON that would churn your sync, a config in a synced folder turns a sync conflict into a broken config, and secrets belong in the Keychain.

Recipes

A recipe is a shell command you keep re-typing, saved as a note. Any note in your Recipes folder above becomes a tool the assistant can call by name — so "rebuild and restart" runs your command instead of the model improvising one.
To add one, create a note in that folder with two frontmatter fields: 
---
description: rebuild and restart the assistant
command: npm start
---
Anything below the frontmatter is a note to yourself.
That note becomes the tool recipe_rebuild_and_restart, named after the file. The description is what the model reads when deciding whether to use it, so write it as the task, not the command.
Why this is safer than letting it use the shell: the model chooses which recipe to run — never what the command says. The command comes from a file you wrote, and there is no argument substitution at all, so it cannot smuggle anything into the string. Recipes still obey the current autonomy mode, and a handful of catastrophic commands are refused even from your own note.

Scheduled jobs

Run something on a schedule. A prompt job asks the model every time it fires. A monitor job runs a shell command first and only wakes the model when that command's output changes — which is what makes checking something every fifteen minutes cheap instead of ninety-six model calls a day.

Five fields separated by spaces, in your local time: minute hour day-of-month month day-of-week. * means "every". */15 means "every 15th". 1-5 means Monday to Friday.
The model runs only when this command's output changes, compared as exact bytes. Make the output stable — sort your results and drop any timestamp, or every tick looks like a change and the saving disappears. A command that fails is treated as an error, never as a change.
Jobs run headlessly — no approval prompts, no questions.
